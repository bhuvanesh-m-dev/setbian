Overview

Firefox is a free and open-source web browser developed by the Mozilla Foundation. It uses the Gecko layout engine to render web pages, which implements current and anticipated web standards.

Key Features

  • Enhanced Tracking Protection
  • Picture-in-Picture Video
  • Customizable Themes
  • Extensive Extension Library
