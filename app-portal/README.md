# Setbian Portal

A simple, elegant App Portal website for the open-source Linux project **Setbian**.

## Project Objective
To create a community-driven app discovery portal that focuses on transparency, licensing clarity, and UX.

## Structure
- `index.html`: Main landing page showcasing apps.
- `style.css`: Global design system.
- `script.js`: Global logic.
- `app/`: Contains individual app pages (e.g., `zen-edit/`).
- `assets/`: Contains static assets like icons.

## How to Run
Simply open `index.html` in your web browser. No build step or backend required.

## Contributing
- Developers can add their apps by creating a new folder in `app/` and adding an entry to `index.html`.
- Follow the design guidelines in `style.css`.
