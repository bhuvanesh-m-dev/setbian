Overview

Firefox Browser, also known as Mozilla Firefox, is a free and open-source web browser developed by the Mozilla Foundation and its subsidiary, the Mozilla Corporation. Firefox uses the Gecko rendering engine to display web pages.

Key Features

  • Enhanced Tracking Protection to block trackers and scripts.
  • Password manager to securely save and access passwords.
  • Customizable themes and extensions.
  • Picture-in-Picture mode for multitasking.
  • A unified search and address bar.
