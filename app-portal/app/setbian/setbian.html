Setbian

Lightweight GUI tool for post-installation setup on Debian-based systems.

System Utilities Productivity MIT License

What this app does

Setbian is a simple, open-source graphical tool designed to streamline post-installation configuration on fresh Debian installations. It provides an intuitive checkbox interface for selecting and installing essential applications and tools, eliminating the need for numerous individual terminal commands. Ideal for beginners and experienced users alike, it requires only an active internet connection to function.

Key Features

  • Checkbox-based selection of popular packages (e.g., Git, Curl, Firefox, VLC, Visual Studio Code, Telegram Desktop, GIMP, and more)
  • Automated dependency resolution and installation
  • Minimal dependencies, built with native Python libraries
  • One-command installation and launch

Technical Details

  • Latest Version: 0.0.5 (as of recent releases)
  • Size: Approximately 50 KB (.deb package)
  • Supported Debian Versions: Debian 11 (Bullseye), Debian 12 (Bookworm), and derivatives
  • Architecture: noarch (Python-based)

Installation Method

wget -O setbian.deb https://github.com/bhuvanesh-m-dev/setbian/releases/latest/download/setbian-latest.deb && sudo dpkg -i setbian.deb || (sudo apt --fix-broken install -y && sudo dpkg -i setbian.deb) && setbian

Alternatively, run directly from source: git clone https://github.com/bhuvanesh-m-dev/setbian.git && cd setbian && python3 main.py
