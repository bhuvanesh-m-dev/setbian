Setbian

Lightweight GUI tool for post-installation setup on Debian-based systems. Simple, fast, and open source.

System Utilities Productivity MIT License
Download .deb

Overview

Setbian is a simple, open-source graphical tool designed to streamline post-installation configuration on fresh Debian installations. It provides an intuitive checkbox interface for selecting and installing essential applications and tools, eliminating the need for numerous individual terminal commands.

Key Features

  • Checkbox-based selection of popular packages (Git, Curl, VLC, VS Code, etc.)
  • Automated dependency resolution and installation
  • Built with native Python libraries (Zero heavy dependencies)
  • One-command installation and launch

Installation

Run this single command in your terminal to download and install:

Copy Command
wget -O setbian.deb https://github.com/bhuvanesh-m-dev/setbian/releases/latest/download/setbian-latest.deb && sudo dpkg -i setbian.deb

Alternative Source Method

git clone https://github.com/bhuvanesh-m-dev/setbian.git && cd setbian && python3 main.py

Technical

  • Version 0.0.5
  • Size ~50 KB
  • Arch noarch (Python)
  • Support Debian 11/12+
